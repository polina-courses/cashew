# Cashew Local — личный форк

Личная версия приложения Cashew (бюджет, Flutter) для одного пользователя. Исходный README проекта остался как есть, этот файл описывает только то, что изменено в форке и как с ним работать.

## Как устроена доставка

- Код приложения: `budget/lib`. Тесты: `budget/test`.
- Репозиторий: `polina-courses/cashew`, основная ветка `main`.
- Сборка идёт в GitHub Actions (`build-apk.yml`). Запускается при push в `main` и в ветки `feature/**`. Ветки с другими именами (`fix/...`) сборку не запускают.
- Рабочий процесс одной правки:
  1. ветка `feature/<имя>` от `main`;
  2. push, ждём зелёный CI (сборка + тесты);
  3. `git merge --ff-only` в `main`, push;
  4. сборка `main` публикует релиз с тегом `build-N` и файлом `cashew-local-N.apk`.
- Установка на телефон: в приложении Настройки → обновление (берёт последний релиз из GitHub Releases), либо скачать APK из релиза.
- Ключи подписи хранятся в GitHub Secrets и в репозиторий не попадают. Никогда не коммитить секреты.
- Локально Flutter может быть не установлен: тогда ошибки компиляции смотреть в аннотациях проверки (`check-runs/<id>/annotations`).

## Что изменено относительно оригинала

- Убраны Pro-реклама и запросы оценки; обновление через GitHub Releases.
- Доходы не требуют категории (по умолчанию «Без категории»), валюта по умолчанию RUB, компактные шапки.
- Кнопка «+»: сначала выбор типа (расход / доход / перевод), затем форма. Новая трата по умолчанию «предстоящая», доход сразу совершённый.
- У транзакции нет заголовка, только необязательный комментарий.
- Подгруппы счёта («конверты»): цели по сумме и дате, рекомендуемое пополнение, заметки, перекладывание, списание из свободных денег, таблица распределения.
- План подгрупп: у каждой подгруппы вид (каждый месяц / каждую неделю / накопление / «Непредвиденное» / без плана) и сумма; у счёта — план на месяц. Месяц календарный, недели = число понедельников в месяце. Поступление раскладывается по плану: ЗП (ближайшее к 12-му) = 2/3, аванс (к 25-му) = 1/3; порядок: закрыть минусы → текущие → накопления из остатка → остаток в «Непредвиденное». Минусов нет: нехватка берётся из «Непредвиденного» → других текущих → накоплений → свободных. В начале нового месяца остатки текущих подгрупп уходят в «Непредвиденное». План хранится в настройках (`envelopePlans`, `walletPlans`, `envelopeSweep`), схема БД не менялась.
- Календарь предстоящих платежей (слот в нижнем меню): сводка по неделе/месяцу и список по датам.
- Главная: список только совершённых операций и отдельная вкладка «Предстоящие» (от ближайших к дальним).
- Упрощённое погашение кредита: без категории и бюджета, переключатель «Со счёта / Без источника».
- Окно несохранённых изменений: «Выйти без изменений» / «Вернуться для редактирования».

## Ключевые файлы

| Файл | Что внутри |
| --- | --- |
| `budget/lib/widgets/envelopes.dart` | подгруппы: карточка счёта, таблица распределения, подсказки |
| `budget/lib/struct/envelopePlan.dart` | чистая логика плана: потребности, раскладка поступления, покрытие нехватки, перенос остатков |
| `budget/lib/database/envelopePlanStore.dart` | хранение плана в настройках, применение к остаткам |
| `budget/lib/database/envelopes.dart` | расчёт остатков и перемещений между подгруппами |
| `budget/lib/database/tables.dart` | схема БД (версия 49) и миграции |
| `budget/lib/pages/addTransactionPage.dart` | форма добавления/редактирования транзакции |
| `budget/lib/widgets/fab.dart` | кнопка «+» и выбор типа транзакции |
| `budget/lib/pages/upcomingCalendarPage.dart` | календарь предстоящих платежей |
| `budget/lib/pages/homePage/homeTransactions.dart` | список на главной и вкладка «Предстоящие» |
| `budget/lib/widgets/appUpdate.dart` | проверка обновлений через GitHub Releases |
| `budget/test/envelopes_test.dart`, `budget/test/envelope_plan_test.dart` | тесты подгрупп и плана (запускаются в CI) |

## Правила

- Если нашли ошибку, сначала воспроизвести тестом (`budget/test`), потом чинить.
- Меняя схему БД, поднимать `schemaVersionGlobal` в `tables.dart` и добавлять миграцию.
- Не переписывать чужие коммиты в ветке без согласования.
